# Customer-Churn-Prediction-Analytics-Platform
Predict and understand customer churn to enable proactive retention strategies using machine learning.

## Project Overview

This project analyzes historical customer behavior, engagement metrics, and demographic data to identify users at risk of churning. By predicting churn early, businesses can take targeted actions to improve retention and customer lifetime value.

## Key features:

1) Automated data preprocessing, feature engineering, and handling of imbalanced datasets using SMOTE.
2) Predictive modeling with XGBoost and other ML algorithms for high accuracy and interpretability.
3) Analysis of key churn drivers to inform product and marketing decisions.

## Tech Stack

- Languages & Libraries: Python, Pandas, NumPy, scikit-learn, XGBoost, imbalanced-learn
- Data Visualization: Seaborn, Matplotlib, Plotly

## Features

- Data Preprocessing & Cleaning: Handle missing values, categorical encoding, normalization. Address imbalanced churn classes using SMOTE.

- Predictive Modeling: Train and evaluate models (XGBoost, Random Forest, Logistic Regression).Evaluate using accuracy, ROC-AUC, precision, recall, and F1-score.

- Churn Insights: Identify key factors driving churn using feature importance and correlation analysis. Provide actionable insights for targeted retention campaigns.
